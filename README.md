# لا تفتح الباب | DO NOT OPEN THE DOOR

نسخة سطح المكتب (Windows) من لعبة «لا تفتح الباب». إنتاج أبو علي.

## تشغيل اللعبة

1. نزّل `DoNotOpenTheDoor.exe` وشغّله بنقرتين، فهو لا يحتاج تثبيتًا.
2. إذا ظهر تحذير Windows («Windows protected your PC»)، اضغط **More info** ثم **Run anyway**. التحذير يظهر لأن الملف غير موقَّع رقميًا.
3. اضغط **F11** للتبديل بين ملء الشاشة والنافذة.

معلومات عن تشغيل اللعبة:

- **لا تحتاج إنترنت:** مكتبة three.js والخطوط مدمجة داخل البرنامج، والبرنامج يمنع أي اتصال بالإنترنت.
- **التقدم يُحفظ تلقائيًا:** يبقى محفوظًا بعد إغلاق اللعبة، في `%APPDATA%\DoNotOpenTheDoor`.
- **قد يتأخر التشغيل قليلًا أول مرة:** الملف المحمول يفك نفسه في مجلد مؤقت عند كل تشغيل، لذلك قد يأخذ بضع ثوانٍ.

## الإصدار 2.0

- رسومات أقوى: ظلال حقيقية من الأنوار والمصباح، إطباق محيطي (SSAO)، توهّج، تنعيم الحواف، تفاصيل بارزة للأسطح، أرض مبلولة، مطر على الزجاج، وسماء بغيوم وبرق. أربع درجات جودة (منخفضة، متوسطة، عالية، فائقة).
- فيزياء: الأبواب صلبة وهي مفتوحة، والكراسي لها تصادم وتنزاح لما تدفعها.
- تقدر تجلس على الكنب والكراسي والجلسة الأرضية: E للجلوس، وE أو Space للقيام.
- أيقونة خاصة باللعبة.

## تحديث اللعبة

1. استبدل `game/game.html` بالنسخة الجديدة من لعبتك، بنفس الاسم.
2. ارفع التعديل إلى GitHub.
3. يبني GitHub ملف EXE جديدًا تلقائيًا، ويتأكد أن اللعبة تعمل داخله.

إذا أضفت للعبة شيئًا يُحمَّل من الإنترنت (مكتبة أو خط جديد)، يتوقف البناء ويذكر الرابط، حتى لا تصدر نسخة لا تعمل دون إنترنت.

## للمطوّر

| الأمر | العمل |
|---|---|
| `npm ci` | تثبيت الأدوات |
| `npm start` | تشغيل اللعبة في نافذة للتجربة |
| `npm run smoke-test` | فحص آلي يتأكد أن اللعبة تعمل |
| `npm run build` | بناء `dist/DoNotOpenTheDoor.exe`، ويُفضَّل تشغيله على Windows |

- `scripts/prepare.js`: يحوّل `game/game.html` إلى `app/index.html` باستبدال روابط الإنترنت بنسخ محلية.
- `main.js`: نافذة اللعبة، وفيها منع الاتصال بالإنترنت ودعم ملء الشاشة.
